## 1. 历史：从感知机到 AI 寒冬

### 1.1 1957：感知机的诞生

1957 年，心理学家 Frank Rosenblatt 发明了 **感知机（Perceptron）**。它的灵感来自生物神经元：

- 树突接收信号 → 细胞体整合 → 轴突输出
- 数学上：加权求和 → 超过阈值就激活

![Fig.1 生物神经元 vs 人工感知机，Rosenblatt 从生物结构中提取了数学模型 =560x](/DeepLearning/Network/01_mlp_02.png)

感知机能做的事，就是画一条直线来把两类数据分开。AND 和 OR 它都能解：

| 输入 | 0,0 | 0,1 | 1,0 | 1,1 |
| ---- | --- | --- | --- | --- |
| AND  | 0   | 0   | 0   | 1   |
| OR   | 0   | 1   | 1   | 1   |

画一条直线就能把 0 和 1 分开，感知机做到了。当时的媒体把它吹上了天："会学习的机器！"

### 1.2 1969：当头一棒，第一次 AI 寒冬

1969 年，Marvin Minsky 和 Seymour Papert 出了一本书《Perceptrons》。书中证明了一个致命缺陷：**单层感知机连 XOR（异或）都解不了**。XOR 是什么？两个输入相同输出 0，不同输出 1：

| 输入 | 0,0 | 0,1 | 1,0 | 1,1 |
| ---- | --- | --- | --- | --- |
| XOR  | 0   | 1   | 1   | 0   |

把四个点画在坐标纸上：**(0,0) 和 (1,1) 是一类，(0,1) 和 (1,0) 是另一类。你没办法用一条直线把它们分开。** 两条直线可以（先一条分出 (0,0)，再一条分出 (1,1)），但感知机只有一层，画不出两条。

![Fig.2 AND / OR 只需要一条直线，XOR 做不到 =560x](/DeepLearning/Network/01_mlp_01.png)

这个发现如同一盆冷水。既然感知机连最基本的 XOR 都搞不定，那之前吹的"超越人脑"就成了笑话。政府砍经费，机构撤项目，神经网络的研究进入了长达十几年的寒冬。

这不是因为 Minsky 故意打压——他提出的问题在数学上是成立的。

### 1.3 1980s：破局的关键两步

走出寒冬需要两个突破。

#### 1.3.1 第一步：加隐藏层。

给感知机中间加一层"隐藏层"，就变成了**多层感知机（MLP）**。一层画一条直线，两层叠加就可以画两条直线，理论上可以画出任意复杂的边界。

这个想法其实不是 1980 年代才冒出来的。早在 1958 年，Rosenblatt 就在他的书里画过三层感知机的结构图：输入层、一个隐藏层、输出层。但有一个关键细节：他那个隐藏层的权重是**随机生成、固定死的，不参与训练**。只有输出层的权重真的在学。

换句话说，Rosenblatt 在他活着的时候，已经站在了"多层"的门口 —— 他甚至知道推开门需要什么，就是没有钥匙。

但这里有一个大问题：**就算权重不是随机固定的，要训练所有层，该怎么设计算法？**

输出层直接连着真实标签，错了能算账，但隐藏层不直接接触标签，它不知道自己"错在哪里"。你想一下这个画面：整个公司的业绩归到 CEO 头上，但 CEO 只认识它的直属下属，怎么把功劳或责任分给下面每个员工？——这就是 **信用分配问题（Credit Assignment Problem）**。

> 一句话记住这一段：**单层是直尺，只能划直线；多层是折尺，能划任意形状。**

#### 1.3.2 第二步：反向传播算法。

信用分配问题的解法，其实早在 1974 年就被一个叫 Paul Werbos 的博士生写进了他的博士论文。Werbos 在哈佛读博期间，用数学推导出了一套方法——利用微积分里的**链式法则**，把输出层的误差一层一层往前"传"回去，每个隐藏层都能算出自己应该调整多少。

但当时他的论文几乎没有引起任何关注。神经网络正值寒冬，没人关心怎么训练它们。

直到 1982 年，一位年轻的计算机科学家 **Geoffrey Hinton** 在卡内基梅隆大学和同事们讨论这个问题，他们独立地重新发现了类似的想法。Hinton 和 **David Rumelhart**、**Ronald Williams** 合作完善了这套方法，并于 1986 年在《Nature》上发表了题为《Learning representations by back-propagating errors》的论文。

这就是今天熟知的**反向传播（Backpropagation）**。反向传播的核心思路很简洁：

1. 前向算：数据从输入层走到输出层，得到预测值
2. 算差距：预测值与真实值之间的误差
3. 反向传：利用链式法则，把误差对每个参数的偏导数从输出层逐层往输入方向传
4. 梯度到了，优化器就可以更新参数

这篇论文的影响力远超预期。Hinton 的方法使得训练多层网络成为可能，直接触发了 1980 年代中期的 **"联结主义革命"（Connectionist Revolution）**。AI 寒冬结束，神经网络重新回到学术舞台中央。

> 一个注脚：2018 年，Geoffrey Hinton 因在深度学习领域的贡献获得了图灵奖（计算机界的诺贝尔奖）。反向传播是他获奖的核心成果之一。

## 2. MLP 的网络结构 — 信息如何流动

### 2.1 整体骨架

MLP 的结构非常简单——从头到尾就是**层叠**：

```
输入层 → 隐藏层 1 → 隐藏层 2 → ... → 输出层
```

每一层和下一层之间是**全连接（Fully Connected）**，意思是前一层的所有神经元，都连到后一层的所有神经元上。

拿一个具体例子来看：输入是 4 个数字（比如一张 2×2 的图片展平），先过隐藏层 1（5 个神经元），再过隐藏层 2（5 个神经元），最后输出层给出 3 个类别的分数：

![Fig.3 MLP 结构图：4→5→5→3 的全连接网络，箭头标注 W 和 b 的位置 =560x](/DeepLearning/Network/01_mlp_03.png)

### 2.2 数学上就只有两步操作

MLP 的每一层都在重复同一个公式：

$$
z^{(\ell)} = W^{(\ell)} a^{(\ell-1)} + b^{(\ell)}
$$

$$
a^{(\ell)} = \sigma(z^{(\ell)})
$$

拆开来看：

1. **第一步**：$W^{(\ell)} a^{(\ell-1)} + b^{(\ell)}$

   第 $\ell-1$ 层的输出 $a^{(\ell-1)}$（例如 4 个值），乘上权重矩阵 $W^{(\ell)}$（形状是 $5 \times 4$），再加上偏置向量 $b^{(\ell)}$（5 个值），得到 $z^{(\ell)}$（5 个值）。

2. **第二步**：$\sigma(z^{(\ell)})$

   把 $z^{(\ell)}$ 的每个值通过一个**激活函数 $\sigma$**，得到第 $\ell$ 层的输出 $a^{(\ell)}$。

就这么简单。整篇文章的所有结构，本质上只是在问一个问题：**你怎么组织这两步操作？**

### 2.3 从用户视角到底层视角

**用户视角：几行代码搞定**

前面讲了两步公式，那在代码里到底怎么写？以 4→5→5→3 的 MLP 为例：

```python
import torch.nn as nn

# 1. 定义模型的网络结构
model = nn.Sequential(
    nn.Linear(4, 5),     # Wx + b，输入 4 个值，输出 5 个值
    nn.ReLU(),            # σ
    nn.Linear(5, 5),     # Wx + b，输入 5 个值，输出 5 个值
    nn.ReLU(),            # σ
    nn.Linear(5, 3),     # Wx + b，输入 5 个值，输出 3 个值
)
```

每行 `nn.Linear(m, n)` 就是做 $Wx + b$，传入 m 个值、输出 n 个值。`nn.ReLU()` 就是激活函数 $\sigma$。训练循环也是一样的模式，不断重复这个模型结构这个过程：

```python
loss_fn = nn.MSELoss() # 2. 定义损失函数
optimizer = torch.optim.SGD(model.parameters(), lr=0.1) # 3. 定义优化器

# 4. 正式训练的完整过程
for batch_x, batch_y in dataloader:
    pred = model(batch_x)          # 前向传播
    loss = loss_fn(pred, batch_y)  # 算损失
    optimizer.zero_grad()          # 梯度清零
    loss.backward()                # 反向传播
    optimizer.step()               # 优化器更新
```

**底层视角：CPU、GPU 在算什么？在算矩阵的加减乘除**

$W^{(\ell)}$ 是一个矩阵，$a^{(\ell-1)}$ 是一个向量，$b^{(\ell)}$ 是一个向量。$W a$ 就是矩阵乘向量，再加偏置。这种方式在计算机里非常高效——GPU 天生适合做矩阵乘法。

| 量                   | 形状             | 含义                                         |
| -------------------- | ---------------- | -------------------------------------------- |
| 输入 $a^{(0)}$       | $4$              | 原始特征的 4 个值                            |
| $W^{(1)}$, $b^{(1)}$ | $5\times 4$, $5$ | 连接输入层和隐藏层 1 的权重, 隐藏层 1 的偏置 |
| $a^{(1)}$            | $5$              | 隐藏层 1 的输出（激活后）                    |
| $W^{(2)}$, $b^{(2)}$ | $5\times 5$, $5$ | 连接两个隐藏层的权重, 隐藏层 2 的偏置        |
| $a^{(2)}$            | $5$              | 隐藏层 2 的输出                              |
| $W^{(3)}$, $b^{(3)}$ | $3\times 5$, $3$ | 连接隐藏层 2 和输出层, 输出层偏置            |
| 输出                 | $3$              | 3 个类别的分数                               |

## 3. 激活函数在 MLP 中的角色

### 3.1 如果不加激活函数

假设没有激活函数，只剩 $z^{(\ell)} = W^{(\ell)} a^{(\ell-1)} + b^{(\ell)}$。那两层串联起来是什么？

$$
a^{(2)} = W^{(2)} (W^{(1)} a^{(0)} + b^{(1)}) + b^{(2)} = (W^{(2)} W^{(1)}) a^{(0)} + (W^{(2)} b^{(1)} + b^{(2)})
$$

两个线性变换的复合，还是一个线性变换。叠一百层也等于一层。回头看 XOR 问题：

- 单层感知机 = 一个线性变换 → 一条直线 → 搞不定 XOR
- 不加激活函数的深层网络 = 还是一个线性变换 → 还是一条直线 → 还是搞不定 XOR

**深度白叠了。**

### 3.2 激活函数的作用：打碎线性

激活函数 $\sigma$ 在每个神经元后面加了一道"非线性关卡"。常见的激活函数有：

| 激活函数 | 公式                         | 形象理解               |
| -------- | ---------------------------- | ---------------------- |
| Sigmoid  | $\sigma(x) = 1/(1+e^{-x})$   | 把任何数压到 0~1 之间  |
| Tanh     | $\tanh(x)$                   | 把任何数压到 -1~1 之间 |
| ReLU     | $\text{ReLU}(x) = \max(0,x)$ | 负数砍掉，正数保留     |

加上激活函数之后，每一层都变成了"先线性变换，再非线性打碎"。两层堆叠就不再等价于一层了：

1. 第一层画三条直线围成一个区域
2. 第二层在这些区域上继续组合
3. 理论上，足够多的层和神经元可以拟合任何形状

这就是 MLP 能搞定 XOR 的原因。如图所示：

- 左图是单层感知机在 XOR 上的决策边界：一条直线，永远分不开四个点。
- 右图是 MLP 的决策边界：两条直线围成一个区域，完美分割。

![Fig.4 XOR 决策边界对比：左单层失败，右 MLP 成功 =560x](/DeepLearning/Network/01_mlp_04.png)

> 一句大白话：**激活函数就是网络的"折纸工人"，每折一下增加一种表达能力。**

## 4. 优化器在 MLP 中如何工作

### 4.1 完整的训练循环

MLP 的训练是一个循环，每步做 4（5）件事：

```
(1) 前向传播         → 从输入算到输出，得到预测值
(2) 计算损失         → 预测值和真实值之间的差距
(3) 梯度清零         → 清零（清空上一次遗留的梯度）
(4) 反向传播         → 把损失对每个参数的偏导数逐层往回传
(5) 优化器更新参数    → 拿着梯度去更新 W 和 b
```

1、2、4 步由网络结构决定，第 5 步由优化器决定。反向传播算出了每个参数的梯度 $\nabla w$。优化器的工作就是拿着这个梯度，决定怎么更新参数。

> 形象理解：**优化器是插在 MLP 骨架上的一个插件，它不改变骨架的结构，只决定拿着梯度怎么走。**

这里要重点说明一下 **梯度清零**，==PyTorch 的梯度是累加的==，每次调用 loss.backward() 计算出的梯度，会加到参数已有的 .grad 属性上，而不是替换它。

通常情况下，要在反向传播之前，把上一次的遗留梯度清零，这样反向传播计算出来的才是下一轮的真实梯度，才可以放心的让优化器去更新参数。

但其实，PyTorch 设计成累加而不是替换，是故意留了一个功能：**梯度累积**。当显存不够、一次塞不进大 batch 时，你可以拆成多个小 batch，每个算完只 backward() 不 step()，等积攒了足够的梯度再一起 step()：

```py
for micro_batch in micro_batches:
    pred = model(micro_batch)
    loss = loss_fn(pred, micro_batch_y)
    loss.backward()              # 累加梯度，不清零
    # ← 不 step，继续下一个 micro_batch

optimizer.step()                 # 积攒够了，统一更新
optimizer.zero_grad()            # 更新完再清零，准备下一轮
```

### 4.2 反向传播：梯度怎么往回流

反向传播的核心是**高数里的链式法则**。

假设网络只有两层：

$$
a^{(1)} = \sigma(W^{(1)} x + b^{(1)})
$$

$$
\hat{y} = W^{(2)} a^{(1)} + b^{(2)}
$$

$$
L = \text{Loss}(\hat{y}, y)
$$

损失 $L$ 对 $W^{(2)}$ 的梯度可以直接算（因为 $W^{(2)}$ 直接连着输出）：

$$
\frac{\partial L}{\partial W^{(2)}} = \frac{\partial L}{\partial \hat{y}} \cdot \frac{\partial \hat{y}}{\partial W^{(2)}}
$$

但对 $W^{(1)}$ 的梯度就要一路往回传：

$$
\frac{\partial L}{\partial W^{(1)}} = \frac{\partial L}{\partial \hat{y}} \cdot \frac{\partial \hat{y}}{\partial a^{(1)}} \cdot \frac{\partial a^{(1)}}{\partial z^{(1)}} \cdot \frac{\partial z^{(1)}}{\partial W^{(1)}}
$$

沿着计算图从输出往输入方向逐层求导，每一层的梯度都依赖上一层传下来的结果。这就是"反向"的含义：**信息从后往前流**。

## 5. 扩展：通用近似定理

既然 MLP 理论上可以拟合任何连续函数，那为什么我们不用它来做图像识别、文本翻译，亦或者其它的现代任务？答案藏在 **通用近似定理（Universal Approximation Theorem）** 里。

### 5.1 定理的“理论上”与“实际上”

1989 年，Cybenko 等人证明了一个结论：

> 一个足够宽的、带一个隐藏层的 MLP，可以任意精度近似任何连续函数。意味着：**只要隐藏层神经元够多，MLP 理论上什么都能学。**

![Fig.5 通用近似定理：隐藏层越多，MLP 拟合越准 =560x](/DeepLearning/Network/01_mlp_05.png)

通用近似定理只保证了存在性：存在一组权重能做到这件事。但它不告诉你怎么找到这组权重，也不保证这组权重能用有限的样本学到。更关键的问题是**效率**。

假设一张 224×224 的 RGB 图片，展平后是 224×224×3 = 150,000 个输入。第一层如果只设 1000 个隐藏神经元，那 $W$ 就是 1000 × 150000——光是权重就有 **4.5 亿个**（占用 1.8 GB 显存，单精度）。而且每个输出都连接了所有输入位置，完全没有利用"相邻像素之间关系更紧密"这个先验知识。

| 结构        | 参数效率 | 利用的先验知识      |
| ----------- | -------- | ------------------- |
| MLP         | 极低     | 无                  |
| CNN         | 高       | 局部连接 + 权值共享 |
| Transformer | 中       | 全局交互 + 位置编码 |

- CNN 告诉网络"只看相邻几像素就够了"，于是参数量从 $O(n^2)$ 降到了 $O(k^2)$（$k$ 是卷积核大小）
- Transformer 告诉网络"全局都看，但通过注意力机制选择性关注"。
- MLP 什么都没告诉，所以它需要海量参数来弥补这个"结构上的空白"。

> 通用近似定理：**MLP 什么都能学，但要学到同样的精度，它需要的参数比 CNN 和 Transformer 多得多。**
