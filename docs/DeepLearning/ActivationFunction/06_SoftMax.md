## 1. 数学原理：把分数变成概率

神经网络做分类任务时，最后一层会输出每个类别的**原始分数**（logit）。比如识别一张图片是猫、狗还是鸟，网络可能输出 $[2.0, 1.0, 0.1]$。

但这些分数有一个问题，原始分数（logit）是网络最后一层的输出，范围可以是任意实数。这些数字本身没有概率意义（2.0 不是"200% 的概率"）。SoftMax 的作用是把它们归一化：每个值在 (0, 1) 之间，加起来等于 1，变成概率分布。

$$
\text{SoftMax}(z_i) = \frac{e^{z_i}}{\sum_{j=1}^{K} e^{z_j}}
$$

![1. SoftMax 工作原理](/DeepLearning/Activation/06_softmax.png)

**举个例子：**

输入 $[2.0, 1.0, 0.1]$，SoftMax 输出 $[0.659, 0.242, 0.099]$。

0.659 表示"这张图有 65.9% 的概率是猫"，0.242 表示"有 24.2% 的概率是狗"，0.099 表示"有 9.9% 的概率是鸟"，三个数加起来等于 1。

### 1.1 温度参数

SoftMax 有一个可选的温度参数 $\tau$：

$$
\text{SoftMax}(z_i, \tau) = \frac{e^{z_i/\tau}}{\sum_{j=1}^{K} e^{z_j/\tau}}
$$

| 温度              | 效果                 | 用途                |
| ----------------- | -------------------- | ------------------- |
| $\tau = 1$        | 标准 SoftMax         | 分类任务            |
| $\tau \to 0$      | 趋近 one-hot（尖锐） | 知识蒸馏（teacher） |
| $\tau \to \infty$ | 趋近均匀分布（平滑） | 知识蒸馏（student） |

打一个比方，还是刚才 “猫、狗、鸟” 的输出：

- $\tau = 1$（标准）：输出 $[0.659, 0.242, 0.099]$，猫的概率最高
- $\tau = 0.1$（低温）：输出 $[0.999, 0.001, 0.000]$，几乎确定是猫（one-hot）
- $\tau = 10$（高温）：输出 $[0.402, 0.335, 0.263]$，概率分布更平滑

低温时，概率集中在最高分的类别；高温时，概率分布更均匀。这就是为什么知识蒸馏中，Student 网络用高温 SoftMax——它能看到更多"暗知识"。

### 1.2 知识蒸馏中的应用：

知识蒸馏是用大模型（Teacher）训练小模型（Student）的方法。关键问题是：大模型输出的"正确答案"信息量太少（只有 0 或 1），小模型学不到东西。

解决方案是用温度参数：Teacher 用低温 SoftMax（$\tau = 1$），Student 用高温 SoftMax（$\tau = 10$）。高温 SoftMax 会让概率分布更平滑，小模型能看到更多"暗知识"（比如"这张图虽然像猫，但也有点像狗"）。

### 1.3 三个关键性质

| 性质          | 说明                             |
| ------------- | -------------------------------- |
| 输出在 (0, 1) | 每个值都是正数                   |
| 输出和为 1    | $\sum_i \text{SoftMax}(z_i) = 1$ |
| 保序性        | 原来大的分数，转换后仍然大       |

**为什么用指数函数？**

- 指数函数 $e^x$ 保证输出为正
- 指数函数会放大差距：$[2.0, 1.0, 0.1]$ 的差距是 1.9，SoftMax 后差距被放大

## 2. 交叉熵损失

SoftMax 通常和交叉熵损失（Cross-Entropy Loss）一起使用：

$$
\mathcal{L} = -\sum_{i=1}^{K} y_i \log(\text{SoftMax}(z_i))
$$

其中 $y_i$ 是真实标签（one-hot 编码）。

**PyTorch 的实现：**

```python
# 方法 1：分开计算
log_probs = F.log_softmax(logits, dim=-1)
loss = F.nll_loss(log_probs, labels)

# 方法 2：合二为一（推荐，数值更稳定）
loss = F.cross_entropy(logits, labels)
```

> 为什么推荐 `cross_entropy`？因为它内部用 `log_softmax` + `nll_loss`，数值计算更稳定（避免 log(0) 的问题）。

## 3. PyTorch 中的使用

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

logits = torch.tensor([2.0, 1.0, 0.1])

# SoftMax（dim 是必填的）
probs = F.softmax(logits, dim=0)
# tensor([0.6590, 0.2424, 0.0986])

# 或者用 nn.Softmax
softmax = nn.Softmax(dim=0)
probs = softmax(logits)

# 分类任务通常用 cross_entropy（内部包含 SoftMax）
loss = F.cross_entropy(logits.unsqueeze(0), torch.tensor([0]))  # 类别 0
```

### 3.1 **dim 参数说明**

**dim 怎么选？**

| 输入形状                 | dim     | 含义                             |
| ------------------------ | ------- | -------------------------------- |
| `[类别数]`               | `dim=0` | 对整个向量做 SoftMax             |
| `[苹果数, 类别数]`       | `dim=1` | 对每个苹果的类别做 SoftMax       |
| `[视频数, 帧数, 类别数]` | `dim=2` | 对每个视频每一帧的类别做 SoftMax |

dim 是 SoftMax 计算的维度，沿着这个维度的每个切片都会求和为 1。具体指向什么维度，取决于你的输入形状和任务类型。**规则**：==dim 是指除了 “类别” 外，还有多少纬度存在。实际的分类，总是指向 "类别" 那个维度==。

**例子 1：一个苹果的分类（dim=0）**

一个苹果，判断是好苹果还是坏苹果。只有 “好” 与 “坏” 两个特征，一个维度，所以用 dim = 0。

```python
logits = torch.tensor([2.0, 0.5])  # [好苹果的分数, 坏苹果的分数]
probs = F.softmax(logits, dim=0)
# 输出: [0.8176, 0.1824]
# 含义：好苹果 81.8%，坏苹果 18.2%
# 两个数加起来等于 1
```

**例子 2：两个苹果的分类（dim=1）**

两个苹果，分别判断是好苹果还是坏苹果。这里不仅有好坏之分，还有苹果的个体之分，它是一个二维的分类，输出是 “哪一个苹果是好的”，所以 dim = 1。

```python
logits = torch.tensor([
    [2.0, 0.5],  # 苹果 1：好苹果分数高
    [0.3, 2.1],  # 苹果 2：坏苹果分数高
])  # shape: [2, 2]
# 第一个 2 是苹果数量，第二个 2 是类别数量

probs = F.softmax(logits, dim=1)
# 输出:
# [[0.8176, 0.1824],  # 苹果 1：好苹果 81.8%，坏苹果 18.2%
#  [0.2557, 0.7443]]  # 苹果 2：好苹果 25.6%，坏苹果 74.4%
# 每一行加起来等于 1
```

**例子 3：视频分类（dim=2）**

一个视频，有 3 帧，判断每帧是 "猫在动" 还是 "猫在睡觉"。这里的视频数量是一个维度，每个视频中的帧是一个纬度，类别 “动 or 睡觉” 是一个维度。所以 dim = 2。

```python
logits = torch.tensor([
    [  # 视频 1
        [1.0, 0.5],  # 第 1 帧
        [0.3, 2.0],  # 第 2 帧
        [0.8, 1.5],  # 第 3 帧
    ]
])  # shape: [1, 3, 2]
# 第一个 1 是视频数量，第二个 3 是时间步（帧数），第三个 2 是类别数量（猫在动、猫在睡觉）

probs = F.softmax(logits, dim=2)
# 输出:
# [[[0.6225, 0.3775],   # 第 1 帧：猫在动 62.3%，猫在睡觉 37.7%
#   [0.1680, 0.8320],   # 第 2 帧：猫在动 16.8%，猫在睡觉 83.2%
#   [0.3318, 0.6682]]]  # 第 3 帧：猫在动 33.2%，猫在睡觉 66.8%
# 每个位置的 2 个值加起来等于 1
```

## 4. 应用场景：什么时候用 SoftMax？

SoftMax 是分类任务的标配，几乎所有的分类网络都用它。

**SoftMax 的使用场景：**

| 场景       | 为什么用 SoftMax         | 例子                          |
| ---------- | ------------------------ | ----------------------------- |
| 图像分类   | 输出每个类别的概率       | ImageNet 1000 类分类          |
| 文本分类   | 输出每个类别的概率       | 情感分析、主题分类            |
| 目标检测   | 输出每个框的类别概率     | YOLO、SSD                     |
| 注意力机制 | 把注意力分数变成概率     | Transformer 的 Self-Attention |
| 知识蒸馏   | 配合温度参数，传递暗知识 | 用 BERT 蒸馏 TinyBERT         |

**SoftMax vs Sigmoid：**

| 特性     | SoftMax                  | Sigmoid                      |
| -------- | ------------------------ | ---------------------------- |
| 输出范围 | (0, 1)，和为 1           | (0, 1)，各自独立             |
| 适用场景 | 多分类（互斥）           | 多标签（不互斥）             |
| 例子     | 图像分类（只能是猫或狗） | 图像标注（可以同时是猫和狗） |

> SoftMax 用 `F.softmax()`，分类任务用 `F.cross_entropy()`（内部包含 SoftMax）。
